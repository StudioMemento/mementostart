# Asset

Wordmark: geometrie dell’SVG originale fornito dall’utente, con glifi scalati uniformemente al 50% e distribuiti sulla stessa larghezza. Conservato dalla V4/V5, senza ricostruzione tramite font.

Icone: il foglio trasparente `icons-v3.png` già presente nel kit, estratto con generazione immagini dalla tavola Memento fornita dall’utente. Conservato senza nuove elaborazioni; ogni viewBox inquadra il proprio simbolo. Non è un export dei modelli 3D originali.

Blur: renderer nuovo, solo CSS, basato sulle proprietà calcolate della pagina Framer di riferimento osservate in Chrome il 3 novembre 2026. Non usa immagini o maschere generate.

Bridge: protocollo V2 e adattatori mantenuti per compatibilità; renderer, nomi CSS, navbar e bootstrap ricostruiti. `brand.mjs` è conservato per eventuali import legacy, non è usato dal nuovo rendering.
